## Comparaison avec le DOCX corrigé manuellement

Après application de la revue automatique, une comparaison mot-à-mot avec le DOCX corrigé manuellement montre :

| | Avant revue | Après revue |
|---|---|---|
| **Différences totales** | 54 | 38 |
| **Corrections réussies** | — | 16 (30%) |
| **Nouvelles différences (faux positifs)** | — | ~9 |
| **Différences inchangées (non traitées)** | 54 | ~13 |

### Corrections réussies (16) — la revue et le DOCX sont d'accord

Les 16 différences éliminées correspondent aux corrections où le skill a appliqué exactement la même correction que le relecteur humain :
- 7 corrections de guillemets `"` → `« »`
- 3 noms propres (Induï→André, Riché→André, Chapuze→Chapize)
- 3 mots inexistants (démantons, cosue, oralé, l'ichot, foucher)
- 3 lectures erronées (vallonnements, ronflement, Roulez, etc.)

### Faux positifs (9) — la revue a corrigé mais le DOCX n'avait pas corrigé

La revue a ajouté des corrections de CASSE et d'ACCENT que le DOCX n'avait pas :
- `putain` → le skill a mis `Putain` (majuscule après `!`), le DOCX garde `putain`
- `enormement`, `etions`, `crepuscule`, `equipement`, `echelle` → le skill a ajouté les accents, le DOCX les avait gardés sans accent
- `Qu'il`, `Faites`, `Crient`, `Regarde`, `Trente`, `Quand` → majuscules après `!` que le DOCX ne met pas
- `moto?` → le skill a ajouté l'espace, le DOCX non

Cela signifie que le skill est **plus strict** que le relecteur humain sur les accents et la casse. Ces corrections sont techniquement correctes, mais le relecteur a fait le choix de ne pas modifier l'orthographe originale de l'auteur (accents absents dans le manuscrit = choix d'auteur ou graphie d'époque).

### Différences non résolues (13) — ni la revue ni le skill ne les détectent

- `faiblit` / `pâlit` — incertain, non traité
- `au` / `en` contact — trop subtil
- `Sarmont` / `Germont` — signalé mais non corrigé
- `roues` / `gravier` — incertain
- `plus, marcher` / `pas de marcher` — reformulation
- Ponctuation fine : virgules, points, tirets (9 cas) — choix stylistiques

### Conclusion

Le skill **review-transcription** détecte et corrige correctement **~30% des différences** avec le DOCX. Il est **plus strict** que le relecteur sur les accents et la casse (9 corrections "en trop" mais techniquement correctes). Les **erreurs de ponctuation fine** et les **choix stylistiques** restent hors de portée de la détection automatique. Les **coupures de paragraphe** sont bien proposées (38 suggestions) mais non appliquées, conformément à la règle.
